# 🧂 Снюс-счётчик — веб-версия

Статичная веб-версия приложения, опубликованная через **GitHub Pages**.
Работает полностью офлайн (после первой загрузки), без бэкенда и зависимостей — только HTML/CSS/JS.

## Что здесь есть
- **Сегодня** — счётчик порций с автосбросом после полуночи, прогресс к дневному лимиту, таймер с последней порции, чистая серия дней
- **История** — статистика (всего / среднее в день / максимум) и список по дням
- **Настройки** — дневной лимит, размер банки, очистка данных, экспорт JSON

Все данные хранятся локально в `localStorage` вашего браузера и никуда не отправляются.

## Установка на телефон (PWA)
Откройте страницу в Chrome/Safari → «Добавить на главный экран» — приложение запустится в полноэкранном режиме.

## Локальный запуск
```bash
cd web && python3 -m http.server 8099
# открыть http://localhost:8099
```
