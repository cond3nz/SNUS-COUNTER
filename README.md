# 🧊 Снюс-счётчик

Счётчик снюса, вкинутого сегодня. Без аккаунтов, без интернета, без рекламы —
все данные хранятся только на вашем устройстве.

**Две версии одного приложения:**

| Версия | Где лежит | Технологии |
|---|---|---|
| 📱 Нативное Android-приложение | [`app/`](app/) | Java, Material 3, SharedPreferences |
| 🌐 Веб-версия (PWA) | [`web/`](web/) → публикуется из [`docs/`](docs/) | Чистый HTML/CSS/JS, localStorage |

---

## ✨ Возможности

- **Дневной счётчик** — сколько порций (паучей) вкинуто сегодня; авторазделение по дням, сброс после полуночи
- **+1 / −1 / произвольное число** — добавление и отмена порций, запись времени каждой порции
- **Лимит дня** — прогресс-бар до суточного лимита; при превышении — предупреждение, тряска и вибрация
- **Таймер** — «с последней порции: чч:мм:сс», тикает в реальном времени
- **Чистая серия** — сколько подряд дней укладывались в лимит
- **Пересчёт в банки** — сколько банок израсходовано по заданному размеру упаковки
- **История** — статистика (всего / среднее в день / максимум) и список по дням с мини-графиком
- **Настройки** — дневной лимит, размер банки, очистка данных
- **Экспорт JSON** — резервная копия истории одним файлом (веб-версия)
- **Онлайн-синхронизация вкладок** — данные обновляются между открытыми вкладками браузера

⚠️ **Никотин вреден для здоровья.** Приложение предназначено для *учёта* потребления, а не для его поощрения. 18+

## 📱 Android-приложение

- `applicationId`: `com.snus.counter`, версия 1.0
- Минимум **Android 7.0** (API 24), target API 34, Java 17
- Экраны: `MainActivity` (счётчик), `HistoryActivity`, `SettingsActivity`, `WebActivity` (веб-версия внутри приложения)

### Сборка APK

```bash
gradle assembleDebug
# результат: app/build/outputs/apk/debug/app-debug.apk
```

или откройте проект в Android Studio (требует JDK 17) и нажмите **Run**.

## 🌐 Веб-версия

Чистый HTML/CSS/JS **без единой зависимости** — достаточно любого браузера.
Логика 1-в-1 повторяет нативный `SnusStore.java`, данные хранятся в `localStorage`.
Работает полностью офлайн; есть PWA-манифест — можно «Добавить на главный экран»
и пользоваться как обычным приложением.

### Локальный запуск

```bash
cd web && python3 -m http.server 8099   # открыть http://localhost:8099
```

(или просто открыть `web/index.html` двойным кликом)

### Встройка в APK (WebView)

Веб-версия также встроена в Android-приложение:
- файлы лежат в `app/src/main/assets/web/`;
- экран открывается кнопкой 🌐 в шапке главного экрана (`WebActivity`);
- включены JavaScript и DOM Storage (localStorage работает офлайн);
- кнопка «домой» возвращает в нативный интерфейс, аппаратная «Назад» листает историю WebView.

## 🚀 Публикация на GitHub Pages

Исходники сайта — в папке [`docs/`](docs/) (это точная копия `web/`).
Деплой настроен через GitHub Actions: [`.github/workflows/pages.yml`](.github/workflows/pages.yml)
запускается автоматически при пуше в `main`/`master` (а также вручную из вкладки Actions).

1. Создайте репозиторий и запушьте ветку `main`:
   ```bash
   git remote add origin https://github.com/<владелец>/<репозиторий>.git
   git push -u origin HEAD:main
   ```
2. Включите Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**
   (первый прогон workflow активирует их автоматически).
3. После зелёного статуса Actions сайт будет доступен по адресу:
   `https://<владелец>.github.io/<репозиторий>/`
